# 🛠️ Project: **Task Dashboard App**

- Shows a welcome or login prompt (using `if/else` or ternary)
- Displays tasks using `.map()`
- Highlights completed vs incomplete tasks (with dynamic styling)

---

## ✨ What You’ll Learn

✅ Conditional rendering using `if/else` and ternary
✅ How to display lists using `.map()`
✅ The importance of the `key` prop in lists
✅ How to visually update items based on data

---

## 🧩 App Overview

When the user opens the app:

- If they’re "logged in", show their task dashboard
- If not, show: “Please log in to view your tasks”

If logged in:

- Show a list of tasks using `.map()`
- If a task is marked as completed → show it in green
- If not completed → show it in red
