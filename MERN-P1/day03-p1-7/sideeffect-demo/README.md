## ✅ **Project Overview: React To-Do App with LocalStorage**

### 🎯 Goal:

Build a simple yet functional To-Do list app where users can:

- Add tasks
- Delete tasks
- Automatically save and load tasks using the browser’s **LocalStorage**

---

### 📚 What You’ll Learn:

- How to use `useState` to manage form input and a list of tasks
- How to use `useEffect` to sync state with LocalStorage
- How to dynamically render lists using `.map()`
- How to handle form submissions and button clicks in React
- How to persist data without using a backend or database

---

### 🧰 Tools & Concepts Used:

- React (Functional Components)
- `useState` hook
- `useEffect` hook
- LocalStorage API
- Event handling (`onChange`, `onSubmit`, `onClick`)
- Basic form and list rendering

---

### 🖼️ App Features:

- 📝 **Task input field** — Add new tasks by typing and clicking "Add"
- 📃 **Task list display** — Shows all added tasks in a neat list
- ❌ **Delete task** — Remove any task with a single click
- 💾 **LocalStorage integration** — Tasks are saved even if you refresh or close the browser
